# 生图 Prompt 模板

## 1. 装饰组重建

根据参考图，生成一个独立的前端 UI 装饰资产。  
只重建这些元素：[描述装饰组，例如左侧星星、中间绿色光晕相机、右侧叶子]。  
不要生成卡片、文字、按钮、边框、红框、手机界面或其他 UI 内容。  
整体风格要保持清新、柔和、精致、适合 App 前端叠加使用。  
背景需要方便后续透明化，不要画灰白透明棋盘格。

## 2. 背景-only 重建

根据参考图，生成一个独立的 App 背景图。  
只保留背景层和装饰氛围，不要文字、按钮、卡片、导航栏、进度条、业务内容。  
保留足够留白，方便前端后续叠加 UI 组件。  
风格、色彩、光感要和参考图一致。

## 3. icon family 重建

根据参考图风格，生成一组统一风格的 icon。  
所有 icon 的颜色、圆角、阴影、线条粗细、视觉比例必须一致。  
每个 icon 都需要单独居中，适合导出为前端静态资源。

## 4. 负面要求

- 不要文字
- 不要水印
- 不要红色标注框
- 不要截图边框
- 不要假透明棋盘格
- 不要额外 UI 卡片，除非用户明确要求
