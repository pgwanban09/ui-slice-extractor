# 资产生产路径判断表

## 选择 crop_or_isolate

当资产满足：

- 截图中已经完整
- 边缘清晰
- 背景干净
- 不需要放大缩小
- 不需要重建设计细节

## 选择 svg_redraw

当资产满足：

- 规则几何图形
- 扁平 icon
- 需要缩放不糊
- 方向和形状需要准确

比如：太阳、月亮、箭头、虚线框、简单 tab icon。

## 选择 scripted_rebuild

当资产满足：

- 必须真透明
- 由圆形、线条、简单叶子、星星、月亮组成
- 需要精确方向
- 生图模型容易画错

比如：月亮方向修正、星星叶子组合、餐食 icon 家族。

## 选择 imagegen_then_transparentize

当资产满足：

- 有柔光 / 渐变 / 插画质感
- SVG 会太硬
- 截图里可见但不适合直接裁
- 需要更像设计稿的自然视觉效果

比如：相机装饰组、带 glow 的 badge、小插画装饰。

## 选择 background_reconstruction

当资产满足：

- 用户要背景-only
- 背景被 UI 内容遮住
- 背景包含食物、场景、氛围光、柔和渐变
- 直接裁切会带出文字和卡片

比如：沙拉背景图、App 首页背景图、上传卡片底图。
