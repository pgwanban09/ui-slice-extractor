# 混合重建工作流

## 第一步：全图视觉扫描

不要只看红框。  
先把整张图当作一个设计系统来理解，找出所有潜在可复用资产。

重点扫描：

- 页面背景
- 模块背景
- 卡片壳
- 图标 / logo
- 装饰组
- 重复状态组
- 小叶子、小星星、小圆点、小光晕
- 被 UI 遮挡但可以推断的背景或装饰

## 第二步：候选资产列表

每个候选资产记录：

- 名称
- 所在区域
- 类型
- 是否需要透明
- 最适合的生产方式
- 是否属于一组 icon family
- 是否需要生图重建
- 是否需要方向校验

## 第三步：选择生产路径

| 方法 | 适合对象 | 输出 |
|---|---|---|
| crop_or_isolate | 干净完整的小图 | PNG / WebP |
| svg_redraw | 规则图标、几何图形 | SVG + PNG |
| scripted_rebuild | 真透明、方向精确、简单形状 | PNG / SVG |
| imagegen_then_transparentize | 柔光、渐变、插画感、SVG 很硬的资产 | 透明 PNG |
| background_reconstruction | 被 UI 遮挡的背景图、氛围底图 | PNG / WebP |

## 第四步：生成 / 重建

根据路径选择工具。

## 第五步：校验

重点检查真透明、假棋盘格、方向、文件命名、manifest。

## 第六步：打包

生成 preview、manifest、validation-report、zip。
